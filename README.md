# MetroFuse

<img src="desktopApp/src/desktopMain/resources/logo.svg" alt="MetroFuse logo" width="96" />

MetroFuse is an offline-first music player for Android and desktop. Play your local library without an account, and add optional plugins for music services, lyrics, or custom interfaces.

## Get the beta

Install the Android APK or extract the Windows x64 ZIP from [MetroFuse Releases](https://github.com/956tris/MetroFuse/releases).

## Plugins

Import plugins through **Settings → Plugins → Installed → Import or update plugin**. The [user guide](docs/user-guide.md) covers setup, sign-in, and audio source order. For development, see the [plugin authoring guide](https://github.com/956tris/MetroFuse-Plugin-Docs).
