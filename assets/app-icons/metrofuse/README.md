# MetroFuse logo pack

`mark.svg` is the two-color logo traced from the supplied reference. `mark-light.svg` and `mark-dark.svg` are transparent one-color variants. Use the `note` variants for small placements such as tray and notification icons.

`original.svg` is the default rounded icon. `original-square.svg` includes the full-bleed background for services that apply their own icon mask. The other eight SVG icons match the theme names in the app. All SVGs use editable circles with a 640 × 640 viewBox.

`preview.png` shows all nine themes.
