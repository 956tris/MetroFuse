Offline-first Material 3 Expressive music player for Android and Desktop with an extensible plugin architecture.

Features:

- Offline-first playback for local music libraries without requiring an account
- Optional JavaScript (.mfp) and native Kotlin (.apk/.jar) plugins supporting Plugin API 1.1.0 & 1.2.0
- Optional custom full-shell UI plugins with host crash recovery
- Provider-independent playback, lyrics, search, queue, and scrobbling pipeline
- Discord Rich Presence, Last.fm and ListenBrainz scrobbling
- Casting to Google Cast, FCast, Sonos, and DLNA
- Listen Together, Android Auto, Android TV, desktop mini player, and immersive canvas player
- Encrypted credential storage via Android Keystore and Windows DPAPI
